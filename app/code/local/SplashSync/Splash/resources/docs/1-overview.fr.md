ERP, CRM, autres boutiques en ligne : chacune de vos applications détient une partie de votre activité.
Le module Splash fait de votre **boutique Magento 1 un canal de vente connecté** à toutes ces
applications, et garde vos données synchronisées en permanence, sans ressaisie ni export manuel. :rocket:

### Pourquoi Splash pour Magento 1 ?

#### :shopping_cart: Toutes vos ventes au même endroit

Les commandes et factures de votre boutique Magento sont exportées automatiquement vers votre ERP,
votre logiciel de gestion ou toute autre application connectée. Vous retrouvez toutes vos ventes
en un seul endroit, quel que soit le canal.

#### :package: Des stocks justes, partout

Les stocks sont critiques pour votre activité ! Un stock mis à jour dans votre ERP l'est aussi dans
Magento : fini les commandes de produits en rupture.

#### :busts_in_silhouette: Une seule fiche client, toujours à jour

Grâce au Linker Splash, les profils d'un même client répartis dans vos applications sont
identifiés et fusionnés. Une modification faite à un endroit est répercutée partout, du CRM à la
boutique.

#### :bar_chart: Une gestion financière qui se remplit toute seule

Commandes, factures et avoirs sont exportés automatiquement vers vos applications de gestion.
Votre suivi financier devient plus simple... et sans effort.

#### :inbox_tray: Magento comme base de données principale ?

Le module sait aussi importer dans Magento les clients et les commandes provenant de vos autres
boutiques en ligne (Prestashop, WooCommerce...). Il suffit de dédier un site web Magento à la
collecte de ces données.

### Ce qui est synchronisé

| Objet Magento | Ce qui est pris en charge |
|---|---|
| Clients | Identité, e-mail, société, date de naissance, abonnement newsletter |
| Adresses | Adresses de facturation et de livraison, téléphone, numéro de TVA |
| Produits | Catalogue, SKU, prix, stocks, images, descriptions, SEO, traductions |
| Commandes | Lignes, statuts, adresses, paiements, transporteur et numéro de suivi |
| Factures | Lignes, totaux HT et TTC, statuts (lecture seule) |
| Avoirs | Lignes et totaux des remboursements (lecture seule) |

### Pensé pour vos usages réels

- :globe_with_meridians: **Multilingue** : chaque vue magasin est associée à une langue, et les
  libellés et descriptions produits sont synchronisés dans toutes vos langues.
- :office: **Multi-sites** : choisissez le site web par défaut qui recevra les clients et produits
  créés depuis vos autres applications.
- :receipt: **Prix maîtrisés** : prix produits hors taxe ou toutes taxes comprises, selon la
  configuration de votre boutique.
- :gear: **Paramétrage fin** : jeu d'attributs et entrepôt par défaut, mode expert pour les
  installations avancées.

### Compatibilité

- Magento **1.9**
- PHP **7.2** ou plus récent
- Un compte Splash Sync actif
